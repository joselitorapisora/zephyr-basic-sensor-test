# zephyr-basic-sensor-test
Basic demos using sensor subsystem and drivers on SAME54


#### Software:

- Zephyr v4.1.0
- Zephyr SDK v0.17.0

#### Hardware:

- SAME54 XPRO
- Various Click boards (see below)
